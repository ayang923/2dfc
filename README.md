
# Code Implementations

This repository provides links to the code implementations accompanying the paper:

> O. P. Bruno and A. Yang, "Two Dimensional Fourier Continuation for Domains with Corners," *arXiv preprint* arXiv:2604.22111 (2026). https://doi.org/10.48550/arXiv.2604.22111

## Implementations

Three implementations of the method presented in the paper are available:

1. **MATLAB Implementation**  
   [MATLAB Code](https://github.com/ayang923/2dfc-matlab)

2. **C Implementation**  
   [C Code](https://github.com/ayang923/2dfc-c)

3. **C/MEX-Accelerated MATLAB Implementation**  
   [C/MEX Code](https://github.com/ayang923/2dfc-matlab-mex)
